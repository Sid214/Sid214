### 🌟 About Me

Hey! I'm **Siddhesh Patil**, a passionate tech enthusiast with a deep fascination for **Cybersecurity**, **Ethical Hacking**, and **System Security**. 

I love exploring how networks operate, identifying vulnerabilities, and building scripts and tools to analyze and defend systems. Whether it’s packet inspection, automating workflows with Python and Bash, or understanding low-level computer architecture, I’m constantly learning and expanding my technical arsenal.

- 🛡️ **Passionate About:** Defensive Security, Network Penetration Testing & Vulnerability Assessment
- 💻 **Active In:** Scripting security tools, automation with Python, and low-level programming in C/C++
- 🐧 **Environment:** Linux power user (Kali Linux & Ubuntu), Windows 11 & macOS
- 🚀 **Philosophy:** *"Security is not a product, but a continuous process."*
