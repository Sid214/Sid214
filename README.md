### 🌟 About Me

Hey there! I'm **Siddhesh Patil**, a passionate technologist focused on **Cybersecurity**, **Ethical Hacking**, and **System Administration**. 

I enjoy uncovering security vulnerabilities, dissecting network traffic, automating tasks through scripting, and troubleshooting complex technical problems. From running network reconnaissance to optimizing multi-OS workflows, I'm driven by continuous curiosity and hands-on experimentation.

- 🛡️ **Passions:** Vulnerability scanning, network packet analysis, reconnaissance & ethical hacking
- 💻 **Development & Scripting:** Writing security scripts & automation tools in Python, Bash, and C/C++
- 🖧 **Networking:** Hands-on experience with routing, switching concepts (CCNA track), and deep packet inspection
- 🔧 **Mindset:** *"Understand how it works, find where it breaks, and build it stronger."*

---

### 🎯 Key Focus Areas

- 🔍 **Vulnerability Assessment & Reconnaissance** — Leveraging tools like Nmap, SpiderFoot, Wappalyzer, and Enum4linux for intelligence gathering and attack surface mapping.
- 🌐 **Network & Traffic Analysis** — Inspecting packet flows, diagnosing network issues, and analyzing protocol behaviors using Wireshark.
- ⚡ **Exploitation & Security Testing** — Practicing penetration testing workflows, credential auditing with Hydra, and exploit research using Metasploit.
- 🛠️ **System Troubleshooting & Maintenance** — Diagnosing operating system anomalies, managing cross-platform environments, and automating repetitive tasks.
